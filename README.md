# Telegram Photo Bot

Бот для красивого оформления фото с текстом.

## Режимы

- **Затемнение** — тёмная полоса по центру + белый текст с тенью
- **Блюр** — размытый фон + чёткий текст по центру
- **Баннер** — фото как фон + полупрозрачный блок снизу с текстом

## Запуск

```bash
cd telegram-photo-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
export BOT_TOKEN="твой_токен_от_BotFather"
python bot.py
```

## Использование

1. Отправь боту фото
2. Напиши заголовок (можно с подзаголовком через `|`)
3. Выбери стиль оформления

### Примеры текста

- `Скидка 50%`
- `Новая коллекция | Весна 2026`
- `Главное событие недели`
